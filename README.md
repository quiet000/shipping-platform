# 🚚 منصة الشحن اللوجستي — Logistics Platform

منصة ويب متكاملة (بالعربية / RTL) لشركات الشحن والخدمات اللوجستية، تشمل:

- **صفحة عامة (Landing Page)** مع حاسبة تتبع فورية للشحنات برقم البوليصة.
- **تتبع عام** بخط زمني لمراحل المعالجة (`/track/{waybill}`).
- **لوحة تحكم إدارية** بإحصائيات لحظية ورسوم بيانية (KPI + Recharts).
- **إدارة الشحنات**: إضافة فردية، استيراد جماعي من Excel (.xlsx/.csv) بـ SheetJS، فلترة وتغيير حالة سريع.
- **الوكلاء والشركات** مع تقارير مالية وتحليلات لكل وكيل.
- **المناديب والشاحنات**: إدارة الأسطول والفريق.
- **إدارة الصلاحيات (RBAC)**: مدير / مشرف / سائق مع صلاحيات مخصصة.
- **نظام إنذارات SLA**: كشف تلقائي للشحنات المتبقّي على موعدها يومان أو أقل.
- **وضع داكن + دعم كامل للعربية** (خط Cairo).

## 🛠️ التقنيات

Next.js 15 (App Router) · React 19 · Tailwind CSS · TanStack Query · Supabase (Auth + PostgreSQL + RLS) · Recharts · SheetJS · Lucide Icons · next-themes

## 🚀 التشغيل محلياً

```bash
npm install
npm run dev
# http://localhost:3000
```

> بدون إعداد Supabase، يعمل التطبيق في **وضع تجريبي** ببيانات وهمية (يمكن الدخول بأي بريد/كلمة مرور).

## 🗄️ ربط قاعدة البيانات (Supabase)

1. أنشئ مشروعاً على [supabase.com](https://supabase.com).
2. من **SQL Editor** شغّل محتويات ملف: `supabase/schema.sql` (جداول + RLS + دالة فحص الـ SLA).
3. أنشئ ملف `.env.local` من القالب:

```bash
cp .env.example .env.local
```

4. ضع القيم:

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
```

5. أنشئ أول مدير من **Authentication → Users** ثم أضف صفاً في جدول `profiles` بوجهه بنفس `id` والدور `admin`.

## 🔔 فحص إنذارات SLA تلقائياً

يوجد خيار «فحص الشحنات الآن» في صفحة التنبيهات، وللتشغيل التلقائي فعّل `pg_cron` وأزل التعليق من السطر الأخير في `schema.sql`.

## 📁 بنية المشروع

```
app/                      # الصفحات (Landing, Track, Login, Dashboard...)
components/               # مكونات واجهة قابلة لإعادة الاستخدام
lib/auth.tsx              # سياق المصادقة والأدوار والصلاحيات
lib/data/api.ts           # طبقة البيانات (Supabase أو بيانات تجريبية)
lib/data/mock.ts          # بيانات العرض التجريبي
supabase/schema.sql       # سكريبت قاعدة البيانات الكامل
```

## 🔒 الأدوار

| الدور | الصلاحيات |
| --- | --- |
| مدير (Admin) | كامل النظام + إدارة الصلاحيات والوكلاء والأسطول |
| مشرف (Supervisor) | إدارة الشحنات، استيراد إكسيل، تعيين المناديب، الإحصائيات |
| سائق (Driver) | شحناته المسندة فقط + تغيير الحالة وتسجيل الملاحظات |
